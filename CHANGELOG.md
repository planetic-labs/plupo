# Changelog

## 0.1.4

- Add a universal app with native support for Apple Silicon and Intel Macs.
- Lower the minimum supported system from macOS 15.7 to macOS 14 Sonoma without changing app behavior.
- Update the DMG installer, website, and README with matching compatibility and download information.
- Add an illustrated shelf workflow and placement guide to the README.
- Document app-specific quarantine removal as an alternative when the standard first-launch approval does not work.
- Fix unavailable packaging dependency versions so the DMG can be built reproducibly.

Runtime testing on Intel hardware and macOS 14 remains outstanding.
