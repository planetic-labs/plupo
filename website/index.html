A quick note on first launch.

Plupo isn’t signed with an Apple Developer ID or notarized by Apple yet. macOS may block the first launch. If you trust the download, try opening the installed app once, then go to System Settings → Privacy & Security → Open Anyway and confirm.

If “Open Anyway” does not work

Only if you trust the release downloaded from our GitHub repository, remove the quarantine flag from the installed app:

xattr -dr com.apple.quarantine /Applications/Plupo.app

This applies only to Plupo. It does not sign, notarize, or verify the app. No sudo or system-wide security change is needed.

A few little details.

How do I install Plupo?

Download the DMG, open it, and drag Plupo into Applications. Eject the disk image and open Plupo from Applications. You’ll find it in your menu bar. See the first-launch note above if macOS blocks it.

Does Plupo move or back up my files?

The shelf references your original files; adding them doesn’t move or back them up. Contents aren’t restored after quitting. When you drag an item into another app, that destination decides how to handle it.

Will it work on my Mac?

Plupo supports Apple Silicon and Intel Macs running macOS 14.0 or later. Drag-and-drop support depends on the source and destination apps. See the README for current limitations.

How do I get updates?

Download the newest DMG from GitHub Releases and replace Plupo in Applications. Release notes show what changed between versions.

Can I help make it better?

Absolutely. Report a bug or share an idea, or explore the code on GitHub. Plupo is free software under the MIT license.
